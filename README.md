A productivity-focused web app for building and managing a reusable library of AI prompts. Users can organize instructions into collections, search and filter templates, save favorites, personalize prompts with variables, preview final text, and import or export data. Built with a local-first approach so core functionality does not require an account or paid AI API.

**Highlights:** reusable prompt library, template variables and preview, collections and favorites, JSON/CSV import and export, responsive interface, local-first workflow, utility tests.

**Stack:** React · TypeScript · Vite · SCSS · React Router · Vitest · Testing Library
